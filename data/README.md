# Dataset Directory

Place your plant disease image dataset here.

Expected structure:

```
plant_dataset/
├── apple_scab/
│   ├── img001.jpg
│   └── ...
├── tomato_early_blight/
│   └── ...
├── grape_healthy/
│   └── ...
└── ...
```

Each sub-folder name becomes a class label.

You can download public datasets such as PlantVillage or use the original university images that came with this project.
